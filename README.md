Formulário de Login e Registro com Tela Dividida
Este é um projeto de front-end que apresenta uma interface de usuário para login e registro, com um design moderno de tela dividida. A página é totalmente responsiva e se adapta a diferentes tamanhos de tela.

✒️ Visão Geral
O projeto consiste em uma única página com duas seções principais:

Boas-vindas (Login): Um painel à esquerda que incentiva o usuário a fazer login caso já possua uma conta.

Criar Conta (Registro): Um painel à direita com um formulário para novos usuários se registrarem, incluindo opções de login social.

O layout utiliza um fundo com imagem fixa e sobrepõe os painéis com um efeito de vidro (glassmorphism), aplicando transparência e desfoque para um visual elegante.

(Sugestão: substitua a imagem acima por um print da sua tela)

✨ Funcionalidades
Layout Responsivo: A tela se ajusta para dispositivos móveis, empilhando as seções verticalmente.

Design Moderno: Uso de backdrop-filter para criar um efeito de desfoque no fundo dos painéis.

Animações Sutis: Efeitos de hover nos botões e links sociais para melhorar a interatividade.

Formulário de Registro: Inclui campos para nome, e-mail e senha.

Login Social: Ícones para login rápido com Google, GitHub e LinkedIn.

🚀 Tecnologias Utilizadas
Este projeto foi construído utilizando as seguintes tecnologias:

HTML5: Para a estrutura e semântica do conteúdo.

CSS3: Para estilização, layout com Flexbox e responsividade.

Nenhum framework de CSS ou biblioteca JavaScript foi utilizada, o projeto é feito com código puro.
